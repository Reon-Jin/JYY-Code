Apply one or more exact string replacements to a single file atomically.

Usage:
- `edits` is an ordered array (1-50) of `{ oldString, newString, replaceAll? }`.
- All edits are applied to an in-memory copy first; if any edit fails, the file is not changed.
- The edit fails if `oldString` is not found, or if it matches multiple times and `replaceAll` is false. Provide more surrounding context to make it unique, or set `replaceAll` to replace every occurrence.
- Read the file with the `read` tool before editing so your strings match the exact file content.
- To create or overwrite a whole file use `write`. To delete or move files use `bash` (rm/mv on POSIX, Remove-Item/Move-Item on Windows).

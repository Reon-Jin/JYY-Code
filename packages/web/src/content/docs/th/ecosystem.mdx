ชุดโครงการชุมชนที่สร้างขึ้นบน JYYCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ JYYCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-jyycode](https://github.com/awesome-jyycode/awesome-jyycode) และ [jyycode.cafe](https://jyycode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
